# PeriodePlanner

Vue 3 + Vuetify web application for planning school periods from a public Google Spreadsheet.

## Features
- Planner view with URL-shareable filters for years, weeks and subjects
- Google Sheets CSV loading for weeks, events, subjects, tests and week descriptions
- Markdown rendering for descriptions
- PDF export of the current planner view
- Admin upload flow for PDF/DOCX to Claude-powered CSV conversion
- Settings stored in localStorage for spreadsheet and Claude API configuration

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
